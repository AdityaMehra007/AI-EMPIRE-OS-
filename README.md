## 📌 Overview

**AI-EMPIRE-OS** provides an execution playbook and autonomous agent skill infrastructure for modern AI operators. It bridges high-leverage AI capability building with autonomous career acceleration and automated job pipelines.

---

## 🚀 Core Modules

### 1. 📖 AI Operator Mastery OS
* **File:** [`AI_OPERATOR_MASTERY_OS.md`](AI_OPERATOR_MASTERY_OS.md)
* **North Star Principles:** Compounding capability across five core execution loops:
  1. **Learn fast:** Rapid model and architecture synthesis.
  2. **Build fast:** Artifact-first prototyping and deep modularity.
  3. **Sell fast:** Distribution-first execution and client positioning.
  4. **Automate fast:** Deterministic workflow DAGs and autonomous loops.
  5. **Scale with systems:** Reusable agent skills and institutional memory.

### 2. 🤖 `find-a-job` Autonomous Agent Skill
* **Directory:** [`find-a-job/`](find-a-job/)
* **Specification:** Complete agent skill architecture implementing:
  * Role targeting and ATS keyword alignment.
  * Specialized agent sub-roles for portfolio curation, outreach sequencing, and compensation negotiation.
  * Domain reference data for market compensation floors and recruiter dispatching.
