# Find a Job

## Operating Principles

- Start by clarifying the user's target role, geography/remote preference, seniority, constraints, timeline, work authorization, compensation needs, and current materials.
- If current market data, company details, job postings, salary ranges, recruiters, or deadlines matter, browse the web and cite sources.
- Treat the job search as a pipeline: targets → tailored materials → applications/referrals → interviews → offers → negotiation.
- Prefer concrete artifacts over generic advice: rewrite bullets, draft messages, create trackers, generate practice answers, and propose next actions.
- Never invent credentials, employment history, degrees, certifications, or measurable impact. Ask for missing facts or mark placeholders clearly.

## Core Workflow

1. **Intake**
   - Gather: current resume/LinkedIn, target titles, industries, location, remote/hybrid/on-site preference, visa/work authorization, salary target, availability, strengths, gaps, and constraints.
   - If the user is unsure, propose 2-4 role hypotheses based on their experience and ask them to pick or rank them.

2. **Positioning**
   - Define a concise positioning statement: target role + strongest differentiators + proof points.
   - Identify required keywords and skills from real job descriptions when possible.
   - Separate must-have facts from aspirational language so materials stay truthful.

3. **Materials**
   - Tailor resumes to a specific job description by aligning summary, skills, and bullets to the employer's requirements.
   - Convert responsibilities into achievement bullets using action + scope + method + result. If metrics are unknown, ask for them or use truthful non-numeric outcomes.
   - Draft cover letters only when they add targeted evidence not already obvious from the resume.
   - Improve LinkedIn headlines, About sections, experience entries, featured items, and recruiter-search keywords.

4. **Search Strategy**
   - Build a prioritized target list by role fit, company fit, hiring signal, network access, and application deadline.
   - Recommend a weekly cadence: applications, referral asks, recruiter outreach, follow-ups, interview prep, and pipeline review.
   - Encourage quality over volume for high-fit roles, with light-touch applications for secondary targets.

5. **Networking and Outreach**
   - Draft short, specific messages for referrals, hiring managers, alumni, recruiters, and informational interviews.
   - Include context, relevant fit, a simple ask, and a low-friction next step.
   - Track follow-ups and avoid spamming.

6. **Interview Preparation**
   - Create likely interview questions from the role, company, and user's background.
   - Prepare STAR/CAR stories: situation, task/challenge, actions, results, reflection.
   - Run mock interviews when asked, give direct feedback, and refine answers.
   - Prepare questions the user can ask the interviewer.

7. **Offer and Negotiation**
   - Compare total compensation, benefits, role scope, manager fit, growth path, location expectations, and risk.
   - Draft negotiation emails/scripts that are confident, appreciative, and grounded in market data or competing value.
   - Do not provide legal, tax, or immigration advice beyond suggesting the user consult a qualified professional.

## Task Playbooks

### Resume Tailoring

Use this sequence:

1. Extract job requirements, keywords, responsibilities, and signals of seniority.
2. Map the user's evidence to those requirements.
3. Rewrite only with truthful details.
4. Prioritize the top third of the resume for the target role.
5. Return an edited version plus a brief explanation of major changes.

Read `references/resume.md` for bullet formulas, section guidance, and ATS checks.

### Application Pipeline

When the user wants structure, create a table with:

- Company
- Role
- Posting URL
- Fit score
- Referral/contact
- Deadline or posting date
- Status
- Next action
- Follow-up date
- Notes

Read `references/pipeline.md` for scoring, cadence, and review rituals.

### Outreach Drafting

For each message, identify the recipient type and choose the right format:

- Referral request
- Recruiter introduction
- Hiring manager note
- Alumni or community informational request
- Follow-up after no response
- Thank-you after interview

Read `references/outreach.md` for concise templates and adaptation rules.

### Interview Prep

When preparing for interviews:

1. Build a story bank from the user's projects and achievements.
2. Match stories to competencies in the job description.
3. Draft crisp answers, then practice aloud through mock Q&A.
4. Provide feedback on structure, specificity, confidence, and gaps.

Read `references/interview.md` for question banks and answer patterns.

## Output Standards

- Be specific to the user's target role and evidence.
- Separate immediate next steps from longer-term improvements.
- Use tables for trackers, target lists, role comparisons, and weekly plans.
- Flag assumptions and placeholders visibly.
- When browsing, include links to postings, salary sources, company pages, or networking targets used.
